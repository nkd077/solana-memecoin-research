# Почему копирование «китов» на Pump.fun не окупается — research-стенд на Solana

[English version](README_EN.md)

Асинхронный Python-стенд, который проверяет торговые гипотезы о мемкоинах на реальных
on-chain данных Solana (плюс разведка Robinhood Chain). Бот умеет всё, что нужно для
живой торговли — сканирование сети, разбор транзакций, скоринг, риск-менеджмент,
исполнение через Jupiter/Jito и PumpPortal, — но работает в режиме `DRY_RUN`: каждая
идея сначала измеряется, и только потом (если бы цифры позволили) на неё ставились бы деньги.

**Цифры не позволили.** Ниже — что именно измерено и как.

## Методология: как не обмануть себя цифрами

Самое ценное в проекте — не код исполнения, а ошибки измерения, пойманные по дороге.
Каждая из них по отдельности превращала убыточную стратегию в «прибыльную»:

| Ошибка | Как проявлялась | Чем исправлено |
|---|---|---|
| Мёртвые пулы считались живыми | «≥ 1 сделки в час» пропускал пулы на $18 → win rate завышен | строгий `is_exit_tradeable`: непродаваемое = −100% (`research/recompute_honest.py`) |
| Ложные градации | 74% «градаций» имели физически невозможную ликвидность; «эффект деплоера» целиком состоял из них | фильтр ложных градаций по ликвидности |
| Неверные decimals | 38% записей; до починки эффект A7 был **обратным** | `research/fix_decimals.py` |
| Медиана когорты | смешение торгуемых и безфлоатных пулов тянуло медиану вверх («−4%» вместо −95%) | разрез по наличию рынка |
| Метка ≠ деньги | признак отбирал выпускников ×3,2, но доходность была хуже базы | оценка только по honest PnL |
| Уверенные цифры ИИ-ассистента | 5 задокументированных случаев неверных чисел | всё пересчитывается на своих данных |

Принципы:
- **Пререгистрация.** Гипотеза, порог и критерий провала фиксируются до данных (A7, A11, аудит внешнего канала).
- **Одно окно ≠ n наблюдений.** 457 наблюдений из одного рыночного отрезка — одна ставка, а не 457.
- **Чужие заявления проверяются на своих исходах.** Сигналы внешнего Telegram-канала сохраняются в момент получения, до исхода (`channel/`, `research/ext_signals.py`).

## Архитектура

```
Helius WS / RPC ──► chain_scanner / ws_scanner ──► tx_parser (Pump.fun, Raydium)
                                                        │
                    wallet_screener · rug_checker ◄─────┤
                    wallet_profiler · funding_graph     │
                    insider_detector · accumulation     ▼
                                              scoring / edge_model
                                                        │
                    price_client (Birdeye → DexScreener)│
                    is_exit_tradeable                   ▼
                                                  risk_manager
                                                        │
                    executor: Jupiter + Jito bundle     ▼
                              PumpPortal (проверка tx перед подписью)
                                                        │
                    position_monitor · SQLite · Redis · Telegram · дашборд
```

| Модуль | Что делает |
|---|---|
| `core/chain_scanner.py`, `core/ws_scanner.py` | поток сделок Pump.fun напрямую из сети через Helius |
| `core/tx_parser.py`, `core/pump_curve.py` | разбор транзакций, декодирование событий и состояния бондинг-кривой |
| `core/rug_checker.py`, `core/wallet_screener.py` | mint/freeze-права, концентрация держателей, скам-паттерны кошельков |
| `core/wallet_profiler.py`, `core/funding_graph.py`, `core/insider_detector.py` | репутация кошельков, граф фондирования |
| `core/scoring.py`, `core/edge_model.py`, `backtest/` | скоринг, калибровка LogisticRegression + TimeSeriesSplit |
| `core/risk_manager.py`, `core/position_monitor.py` | размер позиции, лимиты, стопы, частичная фиксация |
| `core/jito_executor.py`, `core/pump_executor.py` | исполнение через Jupiter/Jito и PumpPortal, `DRY_RUN` по умолчанию |
| `core/telegram_bot.py`, `dashboard/app.py` | уведомления и HTTP-дашборд на aiohttp |
| `rhc/` | разведка Robinhood Chain (EVM): события фабрики PONS, деньги в кривых, градации |

**Стек:** Python 3.10+, asyncio, aiohttp, solana-py / solders, curl_cffi, Redis, SQLite, pandas, scikit-learn.
Около 9 000 строк в ядре.

## Запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # вписать HELIUS_API_KEY; DRY_RUN=true по умолчанию
./run_bot.sh                  # бот в paper-режиме, лог в logs/bot_run.log
./run_dashboard.sh            # дашборд: http://127.0.0.1:8787
```

Скрипты замеров запускаются из корня как модули:

```bash
python -m research.recompute_honest
python -m research.track_graduates --report
python -m tests.test_pump_executor
make report                   # сводка по накопленным данным
```

Robinhood Chain (ключ не нужен, публичный RPC):

```bash
python rhc/money.py
```

Подробная установка — [`docs/SETUP_GUIDE.md`](docs/SETUP_GUIDE.md).
